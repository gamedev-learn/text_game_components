# Text Game Components

A collection of reusable components for building text-based games in C++.

This repository is a place for small, independent game systems that can be studied, adapted, and combined in your own projects. Each component focuses on a specific gameplay idea and is designed to be understandable as well as reusable.

## Components

### Door

A door component with support for:

- Open and closed states
- Button, code, and key locks
- Multiple lock types on the same door
- Callbacks for successful actions
- Basic status information
